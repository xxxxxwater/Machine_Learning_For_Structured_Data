# MLSD v0.2.0 — Modern Structured Machine Learning Toolkit

**The first modernized release of Machine Learning for Structured Data (MLSD)** updates the original 2017 academic prototype to support contemporary Python and scikit-learn workflows.

This version focuses on importability, consistent transformer contracts, reproducible evaluation, and inspectable quality gates. It is a **research-oriented release**, not a guarantee of production model accuracy.

## Highlights

- **Heterogeneous features in one frame:** combine ragged time series, numeric bags, raw text, images and scalar observations with strict row-index alignment.
- **Repaired feature transformers:** deterministic statistical features for `BasicSeries` and `BasicBag`, trained-only TF-IDF vocabulary for `BasicText`, and bounded image summaries for `BasicImage`.
- **scikit-learn fit/transform contracts:** `SDataFrame` now fits feature extractors on training samples and transforms held-out rows without refitting.
- **Optional analytical backends:** `BsplineSeries`, `localRSeries`, `tsfreshSeries`, and approximate interpolated-grid `FPCA`.
- **Leakage-aware evaluation:** reproducible `split_frame` / `take_rows` helpers and `PurgedWalkForwardSplit` with a configurable row-based purge gap.
- **Feature-quality guardrails:** audit missing/infinite values, nonnumeric features, constants, duplicate rows and duplicate column names.
- **Modern distribution:** `pyproject.toml`, optional extras, runnable mixed-data training example and automated test/build workflows.

## Installation

```bash
git clone https://github.com/xxxxxwater/Machine_Learning_For_Structured_Data.git
cd Machine_Learning_For_Structured_Data
git checkout v0.2.0
python -m pip install -e .
```

Optional statistical backends:

```bash
python -m pip install -e '.[tsfresh,spline,lowess]'
```

Quick verification:

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
python examples/train_mixed.py
```

## Compatibility and known limitations

**Breaking behavior changes** compared with the pre-2017 prototype include explicit validation exceptions in place of printed errors, fixed-width named transformer output, strict alignment and corrected instance methods.

`FPCA` now means an **interpolated-grid PCA approximation**, not the historical elastic `fdasrsf` implementation. The archived `Example.ipynb`, original `growth.mat` dataset and historical `pyFDA` utilities remain preserved but are **not fully revalidated** against current packages. The row-based walk-forward gap does not infer overlapping financial-event end times; configure the embargo/purge to cover known label horizons, and use event-aware purging for irregular overlapping labels.
